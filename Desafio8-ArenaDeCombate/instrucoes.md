# 🥊 Desafio 8 — Arena de Combate

## Entendendo o Desafio

- Agora vamos aumentar a dificuldade.

Você deverá criar um sistema de combate entre dois personagens, utilizando atributos, cálculos de dano e repetição de turnos.

## Instruções para entrega

### 8️⃣ Desafio Arena de Combate

#### O Que deve ser utilizado

- Classes
- Constructor
- Métodos
- Operadores
- Estruturas de decisões
- Laços de repetição

#### Objetivo

Crie dois personagens.

Cada personagem deverá possuir:

- Nome
- Vida
- Ataque
- Defesa

O dano causado deverá ser calculado através da fórmula:

```text
dano = ataque - defesa
