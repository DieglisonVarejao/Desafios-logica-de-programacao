# 🧩 Desafio 7 — Sistema de Missões

## Entendendo o Desafio

- Neste desafio você deverá criar um sistema capaz de verificar se um herói possui nível suficiente para realizar determinada missão.

## Instruções para entrega

### 7️⃣ Desafio Sistema de Missões

#### O Que deve ser utilizado

- Variáveis
- Objetos
- Estruturas de decisões
- Operadores

#### Objetivo

Crie um objeto representando uma missão.

A missão deverá possuir:

- Nome
- Dificuldade
- Recompensa
- Status de conclusão

O herói deverá possuir um nível.

Determine o nível mínimo necessário para cada dificuldade:

- Fácil = nível 1
- Média = nível 5
- Difícil = nível 10
- Lendária = nível 20

#### Saída

Caso o herói possa realizar a missão:

"{nome} aceitou a missão **{missao}**."

"Missão concluída!"

"Recompensa recebida: **{recompensa} XP**."

Caso não possa:

"{nome} não possui nível suficiente para realizar esta missão."

## 🎯 Desafio extra

- Após completar uma missão, aumente a experiência do herói e verifique se ele subiu de nível.
