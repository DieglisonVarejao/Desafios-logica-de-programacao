# Entendendo o Desafio
- Neste desafio você irá praticar operações matemáticas e estruturas de decisão para criar um sistema de classificação baseado no saldo de vitórias e derrotas de um jogador.

## Instruções para entrega
### 3️⃣ Desafio Calculadora de Rankeadas
#### O Que deve ser utilizado
- Variáveis
- Operadores matemáticos
- Estruturas de decisões

#### Objetivo
Crie variáveis para armazenar:
- Nome do jogador
- Quantidade de vitórias
- Quantidade de derrotas

Calcule o saldo utilizando:
- saldo = vitórias - derrotas

Depois classifique o jogador:
- Menor ou igual a 10 = Ferro
- 11 a 20 = Bronze
- 21 a 50 = Prata
- 51 a 80 = Ouro
- 81 a 90 = Diamante
- 91 a 100 = Lendário
- Maior que 100 = Imortal

## Saída
Ao final deve ser exibida uma mensagem:
- O Herói {nome} tem saldo de {saldo} vitórias e está no nível de {nivel}.
