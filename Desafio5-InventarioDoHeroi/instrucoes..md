# 🎒 Desafio 5 — Inventário do Herói
## Entendendo o Desafio
- Todo aventureiro precisa carregar seus equipamentos. Neste desafio você irá criar um sistema simples de inventário utilizando arrays.
O objetivo é praticar manipulação de dados armazenados em uma coleção.

## Instruções para entrega
### 5️⃣ Desafio Sistema de Inventário
#### O Que deve ser utilizado
- Variáveis
- Arrays
- Laços de repetição
- Métodos de arrays
- Estruturas de decisões

#### Objetivo
Crie um inventário para um herói
O inventário deverá permitir:
- Adicionar itens
- Remover itens
- Listar itens
- Verificar se um determinado item existe

O inventário poderá possuir no máximo 5 itens.

#### Saída
Ao listar o inventário:

Inventário de Link:
- 1 - espada
- 2 - escudo
- 3 - poção
- 4 - arco

Caso o item seja encontrado:
- Item encontrado: poção

Caso contrário:
- Item não encontrado.

## 🎯 Desafio extra
- Impeça que o jogador adicione um item que já esteja no inventário.
