# 🐉 Desafio 9 — Batalha contra o Dragão

## Entendendo o Desafio

- Neste desafio você irá combinar vários conceitos estudados anteriormente para criar uma batalha entre um herói e um dragão.

O objetivo é praticar interação entre objetos, métodos e estruturas de repetição.

## Instruções para entrega

### 9️⃣ Desafio Batalha contra o Dragão

#### O Que deve ser utilizado

- Classes
- Constructor
- Métodos
- Objetos
- Operadores
- Estruturas de decisões
- Laços de repetição

#### Objetivo

Crie uma classe `Heroi` contendo:

- Nome
- Vida
- Dano

Crie uma classe `Dragao` contendo:

- Nome
- Vida
- Dano

Cada personagem deverá possuir um método para atacar.

A cada ataque, a vida do adversário deverá ser reduzida de acordo com o dano causado.

A batalha deverá continuar enquanto os dois personagens estiverem vivos.

#### Saída

Durante a batalha:

"{heroi} atacou {dragao} causando **{dano}** de dano."

"{dragao} agora possui **{vida}** de vida."

"{dragao} atacou {heroi} causando **{dano}** de dano."

"{heroi} agora possui **{vida}** de vida."

Ao final:

"{vencedor} venceu a batalha!"

## 🎯 Desafio extra

- Adicione ataques especiais que possam causar uma quantidade diferente de dano.
