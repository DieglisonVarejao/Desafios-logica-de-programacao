# ⛏️ Desafio 4 — Coletor de Minérios
## Entendendo o Desafio
- Neste desafio você deverá criar um pequeno sistema de coleta de recursos.
O objetivo é utilizar um laço de repetição para simular a coleta de diferentes tipos de minérios e calcular a pontuação obtida.

## Instruções para entrega
### 4️⃣ Desafio Coletor de Minérios
#### O Que deve ser utilizado
- Variáveis
- Operadores
- Estruturas de decisões
- Laços de repetição

#### Objetivo
Crie um programa que receba:
- Quantidade de minérios
- Tipo do minério

Cada minério possui uma pontuação:
- Ferro = 5 pontos
- Ouro = 10 pontos
- Diamante = 20 pontos
- Esmeralda = 30 pontos

Utilize um laço de repetição para processar a quantidade de minérios coletados.

#### Saída
Exemplo:
O jogador coletou 5 minérios de ouro.
Pontuação total: 50

## 🎯 Desafio extra
Faça com que o programa permita coletar diferentes tipos de minério durante a mesma partida.
