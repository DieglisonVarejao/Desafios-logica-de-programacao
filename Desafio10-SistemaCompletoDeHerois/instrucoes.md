# 🏰 Desafio 10 — Sistema Completo de Heróis

## Entendendo o Desafio

- Chegamos ao desafio mais completo desta sequência.

Você deverá utilizar os conceitos de classes, métodos, estruturas de decisão e manipulação de atributos para criar um pequeno sistema de heróis.

A ideia é reunir vários dos conceitos praticados nos desafios anteriores em um único programa.

## Instruções para entrega

### 🔟 Desafio Sistema Completo de Heróis

#### O Que deve ser utilizado

- Classes
- Constructor
- Métodos
- Variáveis
- Estruturas de decisões
- Operadores
- Objetos
- Laços de repetição

#### Objetivo

Crie uma classe `Heroi`.

O construtor deverá receber:

- Nome
- Idade
- Tipo
- Nível
- Vida
- Ataque

O herói deverá possuir um método `atacar()`.

O ataque deverá depender do tipo:

- Guerreiro = espada
- Mago = magia
- Arqueiro = flecha
- Ninja = shuriken

Crie também um método `subirNivel()`.

Ao subir de nível:

- O nível deverá aumentar em 1
- A vida deverá aumentar
- O ataque deverá aumentar

Crie pelo menos 3 heróis diferentes.

Cada herói deverá:

- Realizar um ataque
- Subir de nível
- Realizar outro ataque

#### Saída

Para cada herói deverá ser exibido algo semelhante a:

"{nome} é um {tipo} de nível {nivel}."

"{nome} atacou usando {ataque}."

"{nome} subiu para o nível {novoNivel}!"

"{nome} agora possui {vida} de vida e {ataque} de ataque."

"{nome} atacou usando {ataque}."

## 🎯 Desafio extra

- Crie um método `mostrarStatus()` que exiba todas as informações atuais do herói.

Exemplo:

Nome: Arthas
Idade: 25
Tipo: guerreiro
Nível: 6
Vida: 110
Ataque: 35
