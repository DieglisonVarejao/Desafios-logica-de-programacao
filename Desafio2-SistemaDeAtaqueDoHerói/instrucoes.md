# ⚔️ Desafio 2 — Sistema de Ataque do Herói
## Entendendo o Desafio
- Neste desafio você irá praticar classes, construtores, propriedades e métodos criando diferentes tipos de heróis.
Cada tipo de herói deverá possuir uma forma diferente de realizar seu ataque.

## Instruções para entrega
### 2️⃣ Desafio Sistema de Ataque do Herói
#### O Que deve ser utilizado
- Classes
- Constructor
- Variáveis
- Estruturas de decisões
- Métodos

#### Objetivo
Crie uma classe chamada Heroi.
O construtor deve receber:
- Nome
- Idade
- Tipo

Crie um método chamado atacar().
O tipo do herói deverá determinar seu ataque:
- "guerreiro" = espada
- "mago" = magia
- "arqueiro" = arco
- "ninja" = shuriken

#### Saída
Ao final deve ser exibida uma mensagem semelhante a:
- O guerreiro Thor atacou usando espada.

## 🎯 Desafio extra
- Adicione pelo menos dois novos tipos de heróis e seus respectivos ataques.
